# Overview

This mod is made to address one gripe I've alway had with create mod: Needing to have items on hand to set redstone link frequencies is just too inconvenient. The release of Aeronautics exacerbated this problem with how much redstone link usage it demands, motivating me to make this mod.

---

## Installation

Modrinth: https://modrinth.com/mod/create-redstone-link-gui

Curseforge: https://www.curseforge.com/minecraft/mc-mods/create-redstone-link-gui

## Compatibility

**Create Utilities** is supported in both of its independent distributions, which register under the same `createutilities` mod id:

- **Create Utilities (Unofficial Port)** — package `me.duquee.createutilities`
- **Create Utilities J** — package `io.github.jasonsimpart.createutilitiesj`

Either one enables the Void Link GUI integration (`void_motor`, `void_chest`, `void_tank`, `void_battery`). Neither is a hard dependency: without them the mod works normally and Void Link features are simply absent.
